# Bourse Live Alert Bot

ربات هوشمند مانیتورینگ بلادرنگ بازار بورس تهران برای تلگرام.

## قابلیت‌ها
- رصد صندوق‌های اهرمی و سهام لیدر بازار
- رتبه‌بندی ۵ صنعت برتر بازار
- فیلتر سهام برتر با ارزش معاملات بالای ۱۵ میلیارد تومان
- گزارش‌دهی هر ۱۰ دقیقه یک‌بار در ساعات کاری بازار (۰۹:۰۰ تا ۱۲:۳۰)
- محاسبه تغییرات نمرات نسبت به دوره قبل

## نیازمندی‌های اجرا
متغیرهای زیر باید در محیط سرور تنظیم شوند:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
